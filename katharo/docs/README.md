# Documentation map

Keep authoritative implementation reference separate from explanations and decision history, following the Tropos documentation discipline.

| Document | Purpose |
| --- | --- |
| [Product](product/PRODUCT_MODEL.md) | User problem, workflow and boundaries |
| [Architecture](architecture/ARCHITECTURE.md) | Modules, evidence and execution contracts |
| [Decision record](decisions/0001-local-evidence-and-quarantine.md) | Why deterministic evidence and quarantine |
| [Quality](quality/EVALUATION.md) | Checks, regression cases and release limits |
| [Learning](learning/README.md) | First-principles concepts and tradeoffs |

**Implemented** means executable behavior exists. **Planned** means no executable implementation yet. **Deferred** means postponed until evaluation justifies the additional complexity.
